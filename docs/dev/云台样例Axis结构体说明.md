# 云台样例 Axis 结构体说明

> 历史源码解读：Axis 与 YawGimbal 现已合并为 GimbalAxis。当前接口与验证记录见 [GimbalAxis 单轴封装实施记录](GimbalAxis单轴封装实施记录.md)。

本说明对应 `samples/robotics/gimbal_control/src/main.cpp:36`，仅解释现有代码，不需要修改业务源码。

## 作用

`Axis` 把控制云台一个转轴所需的电机、位置控制封装、单轴云台控制器、配置和就绪状态集中起来。主循环创建 `yaw` 和 `pitch` 两个实例，分别用于水平转动和俯仰，复用同一套处理逻辑。

## 成员

| 成员 | 用途 |
| --- | --- |
| `drive` | 对外部 `motor::Motor` 的引用，不复制电机对象；用于读取反馈、检查状态和设置位置参考。 |
| `axis_motor` | 基于同一个电机创建的 `PositionMotor`，供云台控制器使用。 |
| `controller` | 本轴的 `YawGimbal` 控制器，处理本轴运动命令。 |
| `config` | 保存本轴配置副本；`const` 表示创建后不可修改。 |
| `ready_ms` | 最近一次从未就绪变为就绪的时间，主循环要求遥控命令时间戳晚于两轴就绪时间。 |
| `was_ready` | 保存上次检查的就绪状态，用于识别就绪状态变化。 |
| `reference_seeded` | 记录有限转角轴是否已成功设置过位置参考；参考失效时仍会重新设置。 |

构造函数把外部电机传给 `axis_motor`，再把该电机、`axis_motor` 和本轴配置传给 `controller`，把各层连接起来。

## 三个方法

- `feedbackHealthy(require_reference)`：检查反馈新鲜度、所需位置字段及角度是否为有限数。有限转角轴正常检查时还要求位置参考有效且角度在限位范围内；传入 `false` 时允许先用绝对位置或原生位置检查，为建立参考做准备。
- `ready(now)`：检查电机状态和反馈；必要时为有限转角轴调用 `reseedPosition()` 设置参考，随后重新检查，并在刚进入就绪时记录 `ready_ms`。返回本轴是否就绪。
- `update(rate, stamp, dt)`：把目标角速度、命令时间戳和控制周期包装成遥控来源的 `Rate` 命令，调用 `controller.update()` 并返回其结果。角速度单位为 rad/s，周期单位为秒；主循环将负返回值作为失败处理。

## 调用关系与边界

遥控摇杆 → 主循环计算两轴目标角速度 → 各自 `Axis::update()` → 各自 `YawGimbal` 控制器。随后主循环调用 CAN 总线的 `commit()` 提交输出，提交动作不在 `Axis::update()` 内。

虽然控制器叫 `YawGimbal`，此样例将它作为单轴控制器复用给 pitch；两个实例都通过命令中的 `yaw_rate_rad_s` 字段传递各自角速度，源码对此有明确注释。

`Axis` 只处理单轴相关状态。遥控超时、急停、重新使能条件、两轴组合启停和 CAN 提交由外部主循环负责。这里的方法在云台任务中顺序调用；结构体自身没有额外提供并发同步。
