# 大 Yaw 突发跟转：双板诊断操作指南

最初诊断版只增加观测。当前云台已采用独立 gyro-z 航向（I19=103），不再由 EKF Degraded 撤销 yaw；控制增益、速度/电流上限、底盘目标捕获和电机恢复策略未随这次航向来源修改而改变。附件快照不参与编译，也未修改。

## 独立 yaw 版本先看这里

- I19=103：新版云台，按近似水平的 gyro-z 模型积分；I19=102：旧版三维姿态航向；I19=101：底盘。三者均为 46 通道。
- 上电保持未解锁并静止约 3 秒，必须等 I22=1 再测试。先静置 1 秒，再累计至少 1 秒且 800 个合格静止陀螺样本；标定期仍用加速度模长排除运动，但运行期不再检查加速度/EKF 质量来决定 yaw 是否有效。
- 新版 I10 是独立 yaw 样本年龄；I18 为其去零偏角速度，I23 为其积分角。I24 是安装转换后的原始 gyro-z，`I24-I18` 在同一有效采样附近应近似为固定零偏。
- 新版仍显示 EKF 诊断。急加减速时 I21=4（Degraded）、I26=2（模长拒绝）可以正常出现；只要 gyro 连续、新鲜，预期 I20=0、I22=1、I31 不增加，I37 不含 32。
- I42 是 EKF Tracking 时间，**新版不用于 yaw 有效性**。旧版 Tracking 漏读及 100 ms 预测窗口不再参与新版控制。
- 新版 I20/I13=3 为 gyro/yaw 过期，6 为 gyro 非法/读取失败，9 为时间倒退锁定，11 为速率非法/超 ±35 rad/s，12 为尚未静止标定，13 为有效 gyro 采样间隔超过 20 ms 锁定。I18 无效仍为 NaN，不再用原因 7 表示运行中 EKF 降级。
- 短于等于 20 ms 的有效采样缺口可在新样本到来时梯形连接；长缺口无法恢复缺失角度，会锁定到重启。遥控启停不会重设 yaw=0，EKF 重置也不会改变独立 yaw 的零偏或参考。
- 本次只需烧录新版云台固件即可使用原 v4 航向协议，底盘无需为了协议兼容而修改。底盘原有诊断版可继续使用。
- 平面模型不适合明显倾斜下的精确世界航向，长期纯陀螺 yaw 漂移仍存在。实现与标定条件见 [云台说明](../../applications/sentry_gimbal/README.md)。

适用入口：[sentry_gimbal](../../applications/sentry_gimbal/src/main.cpp) 与 [sentry_chassis](../../applications/sentry_chassis/src/main.cpp)。其他样例仍输出原来的 19 通道，不能直接使用下方新增通道表。

## 1. 编译、烧录和连接

在仓库根目录、已配置好的 Zephyr 环境中执行：

```sh
west build -b dm_mc02/stm32h723xx applications/sentry_gimbal -d build/sentry-gimbal
west build -b dm_mc02/stm32h723xx applications/sentry_chassis -d build/sentry-chassis
# 先保持未解锁，分别接对应板的调试器，再执行相应 flash。
west flash -d build/sentry-gimbal
west flash -d build/sentry-chassis
```

两块板各使用自己的 UART7 诊断串口，115200、8N1、JustFloat。不要把两块板 TX 直接并在一起。可用两个 USB 串口和两个 VOFA 实例同时记录；单串口时先记录云台板，下一次再记录底盘板，但两次故障不能视为同一个事件。

本版保留 I0～I18，追加 I19～I48，总计 49 通道。正常帧 200 字节（含 JustFloat 帧尾），20 ms 一帧约 10000 字节/秒，低于 115200 8N1 的 11520 字节/秒容量，余量约 13%。串口发送仍在低优先级队列线程，不在电机控制线程同步发送。观察 I15/I16 的丢包计数；计数增加时记录有缺口，不能据此判断完整事件顺序。早期只到 I45 的 46 通道日志仍可按本文旧表解析。

先确认 **I19=104 是新版双 Yaw 云台板、I19=105 是新版底盘板、103 是旧版云台板、102 是更早的云台板、101 是旧版底盘板**。启动时可能先收到一帧旧格式启动状态，等待扩展帧后再记录。I0 沿用旧值 1，扩展格式身份以 I19 为准。

VOFA 的 Δt 先设为 **20 ms**。这只是理想绘图间隔，准确时间来自每帧：

```text
本板 uptime_ms = I3 + 65536 × I4
本板 sequence  = I1 + 65536 × I2
```

两块板 uptime 不同步，不能直接相减排因果。分别以本板事件时间定位，结合录像/共同操作标记粗对齐；板间传输本身有延迟，不要声称毫秒级跨板因果顺序。计数器展示低 16 位，65535 后回到 0；时间展示低 32 位。每次重启清零。

## 2. 第一轮只看这些曲线

1. 保持当前已调稳的 PI=0，先静止建立基线，再从低速逐步增加小陀螺速度。不要用手持续阻挡运动中的机构。
2. 云台板画 **I18、I20、I22、I31、I37、I42**。另一个图画 **I26、I27、I28**。
3. 底盘板画 **I7、I8、I9、I20、I29、I35**。另一个图画 **I30、I31、I32**（编码器）。
4. 一旦出现跟转，结束运动并保存包含故障前后过程的完整数值记录，优先导出带全部通道的 CSV。截图需包含板卡 I19、事件计数和时间，不要只截最新数字。
5. 历史波形上的事件与右侧“最新值”可能不是同一时刻。停机后 NaN、Disabled、命令过期不能用于证明驾驶中也发生了相同故障。

## 3. 云台板通道（I19=102/103/104）

I8/I9 是小 Yaw **位置**（rad），I12 是小 Yaw 控制电流（A），I17 是回中误差（rad），I18 是载体世界角速度（rad/s）。I7 表示本地云台执行 Active，不是远端大 Yaw armed。

I18 的 NaN 是程序主动表示航向不可用，不代表编码器算出了 NaN。I13 保留最近一次有效→无效时的原因；新通道 I20 始终是当前原因。

| 通道 | 含义 |
| --- | --- |
| I20 | 当前航向原因，见下表 |
| I21 | 姿态质量：0 不可用、1 Unknown、2 初始化、3 Tracking、4 Degraded |
| I22 | 航向当前可用，1/0 |
| I23 | 可用的载体世界航向 rad；无效时 NaN |
| I24 | 最近陀螺 z，rad/s；102 为安装转换/EKF 去偏后，103 为安装转换后的原始值；是否新鲜看 I41 |
| I25 | 最近加速度模长 m/s²，是否拒绝该样本以 I26/I27 为准 |
| I26 | 最近 EKF 更新的加速度修正结果：0 未评估、1 接受、2 模长拒绝、3 滤波后模长不足、4 创新拒绝 |
| I27 | 该次 EKF 输入的 `abs(norm(accel)-g)`，m/s²；当前模长门限 1.0 |
| I28 | 该次创新 NIS，当前门限 16.27；没算到这一阶段时 NaN |
| I29 | 最近 EKF update 返回码，0 成功；负值是错误或初始化/采样间隔返回值，不等同电机错误 |
| I30 | IMU I/O 错误累计数低 16 位（实现中还可能含部分 service 错误） |
| I31 | 航向有效→无效累计次数低 16 位；启动未就绪不计数 |
| I32/I33 | 最近失效时刻 ms 低/高 16 位 |
| I34/I35/I36 | 该次失效时锁存的 EKF 修正结果/加速度模长误差/NIS |
| I37 | 大 Yaw 许可失败位图；0 表示允许，位定义见下方 |
| I38 | 当前计算的大 Yaw 世界角速度意图 rad/s，非最终 CAN 速度；按原 10 ms 节奏发送 |
| I39 | 对端大 Yaw armed；对端反馈无效时 NaN |
| I40/I41 | 姿态/陀螺样本年龄 ms；无有效 stamp 时为 UINT32_MAX 的 float 近似值 |
| I42 | 距最近一次成功 Tracking EKF 更新的时间 ms；从未成功为 -1 |
| I43 | 104：较小一侧的向外剩余行程 rad（已扣标定、软边界与位置裕量）；103 及更早为 EKF 诊断自身年龄 ms |
| I44 | 正在发生或最近一次航向失效持续时间 ms，恢复后保留 |
| I45 | 当前控制周期 us（旧 I11 可能已锁存历史失效周期） |
| I46 | 104：操作者/裁决给出的原始枪头世界角速度目标 rad/s（未扣载体速度） |
| I47 | 104：分配后可行的枪头世界角速度 rad/s；与小 Yaw 行程、持续预算和加速度约束一致 |
| I48 | 104：分配状态位图。1 分配有效、2 行程受限、4 大 Yaw 意图饱和、8 载体跟踪受限、16 大 Yaw 通道可用、≥32 为分配拒绝原因码（`reason << 5`） |

I37 位图可相加：1 初始化/总线未就绪；2 遥控不新鲜；4 未解锁；8 对端离线；16 安装未确认；32 航向无效；64 小 Yaw 位置无效；128 小 Yaw 控制输出无效。例如 32 单独出现就是航向许可撤销，96=32+64 表示两个条件同时失败。

旧版 102 航向原因 I20/I13：0 正常，1 源不 Running，2 姿态过期，3 陀螺过期，4 参考编号无效，5 姿态数值无效，6 陀螺数值无效，7 Degraded 超许可，8 质量不可用，9 参考重置，10 倾角奇异，11 航向速率非法，12 初始化中，13 SampleGap 锁定，14 应用层 20 ms 新鲜度不满足。新版 103 的原因码和边界以本文开头为准。

EKF 的诊断由 IMU 采集线程产生。成功输出时和姿态/质量在同一锁内发布，失败返回时单独发布带时间戳的诊断；主循环只读取快照，不跨线程读取 estimator 对象。I29 非零时不能把 I26=0 解释为“模长/创新检查通过”。

## 5. 如何判定这次故障

### A. IMU 降级触发撤销

以下是旧版 102 的故障判据；新版 103 应不再因 EKF Degraded 撤销 yaw，反而应使用这些数据验证隔离是否生效。

云台 I31 增加，I13=7，I37 含 32，I18/23 无效；I42 接近或超过 100 ms。

- I34=2：检查失效快照 I35 是否超过模长门限，再查振动、运动加速度。
- I34=4：看 I36 是否超过创新门限；是观测与预测不一致，不等于传感器断线。
- I43 大或 I40/I41 大：要先排采集/调度延迟，不能归因于运动加速度。
- 底盘对应时段 I35 增加且 I18=1/4，支持云台航向失效导致大 Yaw 撤销。只看到 I13=7 但没有新事件时间，可能是旧事件。

### B. 电机/总线问题

云台 I22 保持 1，底盘退出事件增加，I41=10/14 或 I34=3：优先查电机保护。I34=1/8/9 或 I45 非零：优先查 CAN、反馈和传输。原生状态码是证据，不用手感代替。

### C. 编码器回绕

对齐底盘事件时间，检查 I30 是否从 +12.5 跳到 -12.5（或反向），I32 是否相应 ±1，以及 I31 是否连续。

- I30 跳变、I32 正常、I31 连续、事件计数不变：正常回绕，不是失能证据。
- I31 也跳或事件重复与跨界同步：保存原始数据，再查协议范围/反馈中断。仅一次碰巧同时发生不能证明因果。
- I23/I27 在 ±π 跳变是世界角的正常包络；控制器使用 wrap，需看 I28 是否连续，不能把这个也当编码器异常。

### D. 恢复后不回原位或振荡

- I38 增加、I39=1：发生重新初始化捕获，保持目标可能换为恢复时朝向。
- I38 增加、I39=2：世界速率意图归零触发捕获；该意图来自小 Yaw 回中，不一定是操作者松杆。
- I44 增加：90°误差限幅可能移动保持目标。
- I8 与 I29 差很大：目标受加速度斜坡限制；I29 跟上但 I9 跟不上：查电机执行/负载。

## 6. 数据边界与交付

事件在控制周期内捕获，计数、最近时间和关键值持续保留，能发现短于 20 ms 的退出/恢复；但本版不是高速黑匣子，不保存每个控制周期的历史，也不记录两个诊断帧间所有事件的完整序列。多个事件快速连续发生时，以计数增量识别，锁存字段只保留最后一次。

不增加板间协议字段，不改变电机驱动控制策略，不自动恢复/绕过安全许可。保持这次实验的标定参数一致；不要在同一轮同时改 PI、速度、IMU 门限和机械零点。

回传资料：两块板各自 CSV（包含 I0～I45）、故障大致时间、当时是否操作遥控/主动停机，以及本次实际烧录的参数。凭这些才能区分“行驶中的中断”和“结束实验后的过期状态”。
