# CAN1 单 M3508 电机样例实现指南

## 目标与假设

新增 `samples/motor/m3508_can1_speed_control`：CAN1 上仅一台 M3508，减速比 268:17，使用设备树 alias，演示输出轴速度控制。假设使用 DM-MC02、C620 的 CAN 控制模式，电调 ID 为 1；实际 ID、接线和减速比请按硬件确认。下述速度环参数仅用于低速空载调试，需现场整定。

数据流：`can1 alias → CanBus → M3508 Motor → VelocityMotor → 电流命令 → CanBus`。减速比由 Motor 负责换算，控制器目标和反馈是输出轴 rad/s，不要再手动除一次减速比。

## 实施步骤（先完整实现，再做编译检查）

1. 新建目录 `samples/motor/m3508_can1_speed_control/src/`。复制 `samples/motor/dji_speed_control/CMakeLists.txt`、`prj.conf`、`app.overlay`、`src/main.cpp` 到对应位置。将 CMake 的 `project(dji_speed_control)` 改为 `project(m3508_can1_speed_control)`，日志模块名同步改为 `m3508_can1_speed_control`。该样例依赖 `telemetry-uart` alias 和 VOFA；如果不需要 VOFA，删除其 include、节点检查、初始化及发送代码，并从 prj.conf 删除 `CONFIG_SKYWALKER_LIB_VOFA=y` 和 `CONFIG_UART_ASYNC_API=y`。保留串口日志配置。
2. 在 `main.cpp` 的 include 后增加：

   ```cpp
   #define MOTOR_CAN_NODE DT_ALIAS(can1)
   #if !DT_NODE_HAS_STATUS(MOTOR_CAN_NODE, okay)
   #error "An enabled can1 alias is required"
   #endif
   ```

   将 `DEVICE_DT_GET(DT_NODELABEL(can2))` 改为 `DEVICE_DT_GET(MOTOR_CAN_NODE)`；保留 `device_is_ready()` 检查。DM-MC02 板级 DTS 已有 `can1 = &can1;`，无需在 overlay 重复定义；其他板须确认 alias 指向实际连接的 CAN 控制器且节点已启用。
3. 替换原有 `drive` 构造，保留其后的 `bus`、`axis` 及初始化顺序：

   ```cpp
   static skywalker::motor::Motor drive{skywalker::motor::dji::m3508({
       .id = 1,
       .current_limit_a = 3.0f,
       .gear_ratio = 268.0f / 17.0f,
       .timing = {.feedback_timeout_ms = 20, .command_timeout_ms = 20,
                  .enable_timeout_ms = 100, .retry_interval_ms = 100},
   })};
   ```

   不使用整数表达式 `268 / 17`，它会截断为 15；正确比值约 15.7647。ID 是电调设定的电机编号，不是 CAN 控制器号。
4. 为初次调试，将 `kRequestedVelocityRadS` 设为 `0.5f`，保留示例中的 0.8 A 软件电流上限、5 ms 周期和 500 ms 零目标启动。现有目标函数随后会周期性正反转；如需固定方向，将其最后的正弦表达式替换为 `return kRequestedVelocityRadS;`。现有代码会持续请求使能并循环运行，断电是直接停止手段；确认机械空间后再上电。控制环参数不是该减速箱的标定值。
5. `bus.attach(drive)`、`bus.start()`、`axis.configure()` 必须成功后进入循环；循环持续调用 `drive.enable()`、`axis.update(target, dt)`、`bus.commit()`。`dt` 用实际经过时间，单位秒。检查返回的负错误码以及 `axis.telemetry()` 中反馈新鲜度、状态、输出有效性；控制对象及总线保持整个程序生命周期有效。不要再创建或 attach 第二台电机。

## 用户执行的构建和上电检查

完成全部代码后可执行一次编译：

```sh
west build -p -b dm_mc02/stm32h723xx -d build/m3508-can1 samples/motor/m3508_can1_speed_control
```

断电连接 CAN1 的 CAN-H/CAN-L、公共地、合适的终端电阻和 C620 电源，确认电调 ID、CAN 速率及电流模式；固定电机、脱开负载并留出急停方式。上电后观察日志状态、目标、反馈及错误；实际转速应低速跟随目标。若无反馈，先查电调供电、ID、总线接线/终端、电调模式及波特率，再查 alias 和节点状态；若振荡或电流过大，立即断电并重新整定 PID 和限流。
