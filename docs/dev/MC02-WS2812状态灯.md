# MC02 WS2812 状态灯与 C 板兼容

## 当前范围

- 使用 Zephyr `led-strip` 设备，复用 MC02 板载 SPI6/PA7 和 GRB 映射；不引入 HAL SPI 或参考工程的 RGB 渐变。
- `skywalker::led::StatusLed` 是业务对象，`LedPattern` 是颜色与毫秒时长的静态数组。
- 云台、底盘最终应用根据已有 `DiagnosticReason` / `RunStatus` 选择灯语；LED 状态只用于显示，绝不作为运动授权依据。
- 灯语由一个低优先级 Zephyr 线程播放；业务线程只更新请求，不发送 SPI。
- LED 不存在、没有 `led-strip` 设备树别名或 Kconfig 未启用时，`StatusLed` 自动变为无设备引用的空实现。**C 板不需要声明 WS2812 节点**。空实现的 `start/play/setStatus/setColor/off` 返回 0，`available=false`。

## 预置灯语

| 灯语 | 视觉效果 | 触发条件 |
| --- | --- | --- |
| Boot | 紫色 100 ms 闪三次、熄灭 | 启动时一次 |
| Initializing | 蓝色 150 ms、灭 850 ms | 初始化（可手动设置） |
| Ready | 低亮绿色常亮 | 就绪但未运行 |
| Running | 青色 100 ms、灭 900 ms | 执行器运行 |
| Disarmed | 暗黄色常亮 | 遥控未授权、禁止输出 |
| LinkLost | 黄色双闪（120/120/120/640 ms） | 遥控/板间连接失效 |
| Recovering | 蓝色 350 ms、灭 350 ms | 反馈、IMU、命令超时 |
| Fault | 红色 150 ms、灭 150 ms | 初始化、配置、执行错误 |
| EStop | 红色常亮 | **仅在真实急停信号接入时** |
| HardwareTest | 红→绿→蓝→白→灭，每段 300 ms | 手动台架检查 |

颜色在 `include/drivers/led/led_patterns.hpp` 定义，亮度较低。一个正在播放的灯语被新请求立即打断；同一指针的反复 `play` 不重置当前时序，除非传 `restart=true`；非循环序列结束保持最后颜色。

## 应用与自定义用法

```cpp
#include <drivers/led/status_led.hpp>
using namespace skywalker::led;

static StatusLed led;
const int error = led.start();          // 仅 MC02 真正开启后台驱动
(void)led.setStatus(LedStatus::Initializing);
(void)led.setStatus(LedStatus::Running);
(void)led.setStatus(LedStatus::EStop);
(void)led.setColor({10, 0, 0});
(void)led.off();

// 自定义时间序列：颜色、毫秒持续时间；序列本身必须静态存储。
static constexpr LedStep steps[] = {
    {{20, 0, 0}, 100}, {{0, 0, 0}, 100},
    {{0, 0, 20}, 300}, {{0, 0, 0}, 500}
};
static constexpr LedPattern custom{steps, true};
(void)led.play(custom);
```

最终应用始终使用同一个 `StatusLed` 对象。带有 LED 的 MC02 板，`start()` 会检查 Zephyr 驱动是否就绪，失败时返回负 errno，LED 故障不影响电机控制。没有 LED 的 C 板，所有状态接口仍可编译并安全空操作。

## 编译、验证与注意事项

- 状态灯只由两个最终应用的 `prj.conf` 启用 `CONFIG_SKYWALKER_STATUS_LED=y`；MC02 板级 defconfig 仅启用 Zephyr `CONFIG_LED_STRIP=y`，不强制所有样例链接 C++ 灯语播放器。

- MC02：`west build -b dm_mc02/stm32h723xx applications/sentry_gimbal -d ../build/status-led-gimbal -p always`；底盘用 `applications/sentry_chassis`。
- C 板：选用其实际板目标进行编译，确保禁用 `CONFIG_SKYWALKER_STATUS_LED` 或未声明 `led-strip` 时不存在 `DEVICE_DT_GET(DT_ALIAS(led_strip))` 及 WS2812 驱动链接引用。当前仓库没有提供 C 板的 board target，故未能对该板做实际构建。
- 先仅烧录台架验证：手动调用 `led.setStatus(LedStatus::HardwareTest)`，观察红、绿、蓝、白、熄灭。确认颜色正常后再接入机器人执行状态。
- WS2812 更新包含 SPI 同步发送与锁存延时，但只发生在独立低优先级线程，不阻塞电机控制业务线程；底层 SPI 时序是否适合实际灯珠型号仍需实测。
- 临时 `LedPattern` 或临时 `LedStep[]` 不能交给 `play()`；对象指针被后台线程保存，必须是静态生命周期。
- 当前遥控代码的安全档只是 Disarmed，不是 EStop：只有接上真实急停信号后才允许自动选择红色常亮。
