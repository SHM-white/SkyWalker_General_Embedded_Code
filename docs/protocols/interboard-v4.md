# 板间协议 v4：参考工程统一合同

本文件描述已同步至 SkyWalker `main` 与 `dev` 的**当前正式应用发送/接收的参考 v4 版本**（核对基线 `bad529abe5d682797ca27d49078bbf0a9b00266b`，2026-11-10）。兼容目标为
`JJL0612/sentry_gimbal@3cfbe1c` 与 `JJL0612/sentry_onlychassis@dcc8d4e`，
不再承诺兼容 SkyWalker 原有 `0x0405` 扩展或此前的内部 `mode=2`。

## 物理与帧格式

- 云台 USART10 PE3/PE2 ↔ 底盘 USART1 PA9/PA10；460800，8N1。
- `A5 5A | version=04 | role:u8 | id:u16LE | payload_len:u16LE | frame_seq:u32LE | payload | crc16:u16LE`。
- CRC16/CCITT-FALSE：poly `0x1021`、init `0xffff`；整帧长度 `payload_len+14`，最大 142。
- 三份实现均**硬检查 version==4**，没有自动升级或版本协商；不能在不更新参考固件时改帧头为 v5。
- 消息角色：云台=1，底盘=2。多字节数及浮点数小端，float 为 IEEE754 f32。

| ID | 方向 | payload | 用途 |
| --- | --- | ---: | --- |
| `0x0001` | 双向 | 20 | 心跳、源 Boot ID、在线检查 |
| `0x0101` | 云台→底盘 | 32 | 底盘控制（**云台坐标**） |
| `0x0102` | 云台→底盘 | 20 | 裁判许可及功率约束，可选 |
| `0x0103` | 底盘→云台 | 32 | 底盘反馈 |
| `0x0201` | 底盘→云台 | 29～128 | SkyWalker 扩展：裁判原始帧分片，需双板更新 |
| `0x0301` | 云台→底盘 | 36 | 旧可选操作消息；**不再是运行前提**，正式应用不发送 |
| `0x0402` | 云台→底盘 | 36 | 大 Yaw 请求；仅 mode 0/1 |
| `0x0403` | 底盘→云台 | 24 | 大 Yaw 反馈 |
| `0x0404` | 云台→底盘 | 32 | 头部 IMU 航向及角速度（参考原格式） |

## 业务语义

### `0x0101` 底盘行走

| payload offset | 类型 | 含义 |
| ---: | --- | --- |
| 0,1,2,3 | u8 ×4 | mode、source、global_action、保留0 |
| 4,8,12 | f32 | vx、vy（云台系 m/s）、wz（rad/s，逆时针为正） |
| 16,20 | u32 | active_reasons、源命令 sequence |
| 24 | u64 | 目标底盘 Boot ID |

mode=0 Disabled；mode=1 BodyVelocity；mode=2 Spin 编码保留但正式云台只发送 mode=0/1。
global_action=2 Active 才请求运动；0 Disable 为停止。**不需要 `0x0301` 才能执行**。
接收方使用大 Yaw 绝对编码器相对标定前向零位，把云台系 vx/vy 旋到车体系，再进舵轮运动学；
没有有效关节角时平移必须置零，旋转按本地执行器状态处理。小陀螺边平移的参考降速
按旋转前的原始方向选择：有 vy 时 ×0.4，仅 vx 时 ×0.3。
参考底盘的方向约定为 `theta = -1 * (raw_encoder - (-1.132792rad)) / ratio`，
实际安装方向和零位仍需实车校准。

### `0x0402` 大 Yaw 世界角速度

| payload offset | 类型 | 含义 |
| ---: | --- | --- |
| 0..3 | u8 ×4 | mode（0 Disabled、1 FollowCenter）、permission_valid、permission_enabled、保留0 |
| 4 | f32 | 目标**头部对世界**角速度，rad/s |
| 8,12,16 | u32 | 源 sequence、源年龄、命令年龄 |
| 20 | u64 | 目标底盘 Boot ID |
| 28,32 | u32 | 许可年龄、请求 sequence |

为适配未修改的参考底盘，mode=1 只有世界角速度一种含义，不再复用过去的
“直接控制大 Yaw 关节相对速度”解释。SkyWalker 底盘旧速度执行后端通过 BMI088
车体角速度与 `0x0404` 头部角速度换算关节目标；可选 MIT 航向后端直接消费世界意图。
来源年龄、命令年龄、接收 boot、许可、反馈失效时停止输出。

### `0x0404` 头部航向

| offset | 类型 | 字段 |
| ---: | --- | --- |
| 0..3 | u8 + 3B | valid（0/1）、保留零 |
| 4,8 | f32 | 启动软件零位相对航向 rad、头部世界偏航率 rad/s |
| 12,16,20 | u32 | 真实采样年龄 ms、sample_sequence、zero_generation |
| 24 | u64 | 目标底盘 Boot ID |

payload 固定32字节，**没有发送方 Boot ID**；接收侧从已接受心跳取得发送方会话。
源样本年龄有效窗 50ms，不能因重发重复样本延长。该原版格式不能从单帧识别
“旧发送方但目标 Boot 仍相同”的伪造/积压消息；不要把它宣传为具有 `0x0405` 的旧发送方
识别能力。

### `0x0103/0x0403` 执行状态

线上状态沿用参考项目：0 Waiting、1 Starting、2 Running、3 Stopping、
4 Fault、5 Disabled。SkyWalker 内部 `ExecutionState` 使用另一套枚举；
编码和解码必须经过映射，不能直接 `static_cast` 传输。
`ready`/`armed` 只是观测，不能替代有效运动命令。

## 遥控停车和恢复

仅左拨杆 Down 作为人工停车控制；上电、断线及从 Down 重新解锁要求：
左 Down + 右 Middle + 摇杆/拨轮归中 500ms，然后左 Down→Middle 建立解锁，
左 Up 进入手动。右拨杆在进入手动后必须见过 Middle，
主动切到 Down 才请求小陀螺，主动切到 Up 才请求发射。
键鼠发射也必须先看到左右键均松开，才能重新响应按键。
独立的 `clear_estop` 遥控手势不再生成。

断线、原始命令超时（默认100ms）、对端重启、反馈或电机故障仍要停机；
这属于控制输入/执行有效性，不是新增人工急停协议。

## 验证边界

源码已按上述合同更新；测试覆盖 v4 头部、`0x0404` 固定布局、
反馈状态数值、坐标与重解锁状态。**编译/主机测试不能证明实机**
CAN ID、MC02 引脚、机械零位、正方向、控制环参数及停止时限已验收。
参考端 UART 发送忙、反馈丢失以及部分指令序号处理仍是参考固件既有限制，
本 PR 不修改它们。

## SkyWalker 裁判原始帧扩展 `0x0201`

此扩展保持 v4 帧头及既有控制格式，不代表旧参考固件已支持该消息。实现链路为：底盘原生 USART10 PE2 RX → 底盘裁判 CRC 校验 → 底盘 USART1 板间链路 → 云台 USART10 → 云台重组/CRC 校验 → 云台 USART1 PA9 TX → 导航上位机。两块板都需要更新本仓库应用。

| payload offset | 类型 | 含义 |
| --- | --- | --- |
| 0 | u64LE | 底盘发送方 Boot ID |
| 8 | u64LE | 目标云台 Boot ID |
| 16 | u32LE | 原始帧传输 ID，同一原始帧各分片相同 |
| 20 | u32LE | 原始帧在底盘入队后的年龄，ms |
| 24 | u16LE | 原始帧总长度，9～256 字节 |
| 26 | u16LE | 当前分片在原始帧中的偏移 |
| 28 | bytes | 1～100 字节原始数据，包含完整原帧中的相应字节 |

偏移 0 开始重组，后续必须连续且传输 ID、总长度、双板 Boot ID 匹配。分片组装时限 100 ms，源年龄及排队期限最多 300 ms；失联、重启、缺片、队满时允许丢帧，不重放历史状态。板间底层 CRC 与原始裁判 CRC 分别校验。云台解码许可时保留传输年龄，不因重新接收或轮询刷新许可源时间。

发送端优先发送原有心跳及执行反馈，裁判分片仅使用当前批次剩余空间。每板 TX/RX 队列最多各 8 个原始帧；裁判转发不要求遥控解锁，不能代替运动授权。
