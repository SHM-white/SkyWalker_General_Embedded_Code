# 算法单元测试与耗时

使用真实的控制库、CMSIS-DSP 矩阵运算和机器人算法，按 Zephyr ztest / Twister 标准组织。所有输入确定且可重复，不需要传感器或电机。

| 模块 | 正确性依据 |
| --- | --- |
| 四元数 EKF 与姿态工具 | 独立闭式姿态/重力/角速度公式、静态倾角、运动轨迹、偏置与噪声、归一化、多实例、异常输入和时间、加速度及新息门限 |
| 线性卡尔曼 | 一维和二维有理数闭式解、耦合双通道观测、逐步双精度参考、噪声 RMSE 改善、缓冲区尺寸和失败不变性 |
| 矩阵 | 已知非方阵乘积/转置、加减、已知逆矩阵与单位阵、奇异矩阵及维度错误 |
| PID / 前馈 / 前馈 PID | 各项数值、滤波、死区、饱和、积分冻结与抗饱和、组合输出 |
| 参考与串级控制 | 非对称斜率限制、角度跨圈、最短路径、速度滤波与位置/速度串级输出 |
| 舵轮运动学 / 单舵轮 / 四舵轮 / 功率限幅 | 刚体平移与旋转、统一速度缩放、输出轴单位与轮径换算、连续舵向和翻轮向量、四轮映射、整组失败不变性、静止角度保持、功率/缓冲缩放与恢复斜率 |

在仓库根目录运行：

```sh
west build -b native_sim/native/64 tests/algorithms -d build/algorithm_units
build/algorithm_units/zephyr/zephyr.exe
```

与命令仲裁测试一起运行并保存逐用例结果：

```sh
west twister -T tests/algorithms -T tests/command_manager \
  -p native_sim/native/64 --inline-logs -O build/twister-algorithms
```

每个 `BENCH` 行输出测量调用次数、总纳秒数、平均纳秒/调用，以及 16 个批次平均值中的最小/最大值。另有 64 次预热，不计入次数与总时间；断言、打印和结果正确性检查均在计时区间外。调用中必要的输入赋值、返回码收集及循环开销计入测量；矩阵求逆会修改输入，因此对应项目明确标记包含输入复制。

对四元数旋转这样的内联函数，基准对每次输入和输出设置编译器屏障，阻止常量折叠及循环消除；对应输入复制和结果保留开销也计入耗时。

native_sim 使用在 native runner 编译的宿主 `CLOCK_MONOTONIC`，避开执行算法时不推进的模拟时钟。共享工具在其他平台使用 Zephyr timing API；若需要 MCU 耗时，应在目标板编译并运行这些纯算法用例，同时确认该板计时器分辨率足够。当前 Twister 自动运行平台为 `native_sim/native/64`。

耗时随 CPU、编译选项、系统负载和调度变化；这里启用 `CONFIG_SPEED_OPTIMIZATIONS`，不设跨机器的性能通过阈值。批次最小/最大值不是单次最坏耗时，也不代表 MCU 周期数或硬实时保证。测试验证列出的模型与边界，矩阵 flash 存储、硬件驱动和真实闭环调参不在本套件范围内。
