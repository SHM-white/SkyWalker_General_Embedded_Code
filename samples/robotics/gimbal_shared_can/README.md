# 云台共享 CAN 与键鼠发射

CAN1 统一连接小 Yaw GM6020、两个摩擦轮 M3508 和拨盘 M2006，Pitch DM4310 在 CAN2。三个故障组为云台、摩擦轮、拨盘。应用完成本轮控制后，每条物理 CAN 总线提交一次；末尾休眠初值 5 ms，实际周期还包括计算、发送和调度。连接、方向和机械范围取自 `include/robotics/vehicle/calibration.hpp`，沿用工作区现有确认值。

## 操作

先左 Down、右 Down，双摇杆与拨轮归中保持 500 ms，再拨左 Middle 解锁。左 Down 撤销运行；失联后重新解锁。清故障沿用安全档归中后右 Up 保持 1 秒的手势，清除后重新解锁。console 仅输出日志。

| 已解锁后的输入 | 行为 |
| --- | --- |
| 左 Middle | 物理 RC 控制云台/发射 |
| RC 右 Down / Middle / Up | 停摩擦 / 预热 / 直接请求连发 |
| 左 Up | 切换 DR16/DBUS 透传键鼠，两档均为手动控制 |
| 鼠标移动 | 控制 Yaw/Pitch，与右键开摩擦独立 |
| 按住右键 / 松开右键 | 请求开启摩擦 / 关闭摩擦并撤销供弹 |
| 左键普通点击 | 立即请求一发，不等待下一次点击 |
| 相邻左键按下间隔 <500 ms | 从第二次点击起连发，松开间隙仍保持；最后一次按下满 500 ms 后撤销 |
| 左键持续按住 ≥250 ms | 转为连发，释放后撤销，不重复追加首次单发 |

恰好 500 ms 属于新的普通点击。快速连点、长按与 RC 连发共用 `vehicle::requested_fire_rate_hz`，点击快慢不改变射频；初值 5 Hz，执行速度还受机构上限约束。连点结束存在 500 ms 判定窗口，立即撤销可松右键；输入有效期仍为 100 ms。首次启动、来源切换、失联、清故障或队列溢出后，须先收到左键释放，不能以已经按着的左键自动触发。

## 执行与输入合同

接收线程在每次成功解码后保存完整原始帧到 32 帧有界队列；命令线程是唯一消费者，普通诊断快照不消费队列。溢出撤销会话，过期输入不重放。持续手势只归命令线程管理；执行线程只根据实时松键/撤权继续撤销最终仲裁命令。单发编号与原始生产戳不随仲裁刷新，拒绝或过期的事件消费后不补发。

单发用 PositionMotor 控制下一机械分度，按实际位置误差、速度及稳定保持时间判断完成。已经接受的一格可先完成再进入连发；持续供弹用 VelocityMotor，目标为 `fire_rate_hz × dial_step_rad` 并施加速度上限。正常撤销连发后速度目标归零、受控减速，随后从有效机械相位建立下一分度。右键释放、安全档、失联、故障走停机路径。`shots` 仅为热量/供弹预留次数，`completed_single_events` 仅表示机械单发到位，均不是弹丸实发检测。

默认空载模式绕过未接入的裁判许可和热量源，仅供无弹调试。加载模式仍需真实许可、热量、拨盘参考和云台状态；`PendingHeatSource` 与未接入的许可不会伪造有效数据。不刷写或自动运行固件，尚未进行实机调参。

鼠标默认按 DR16 速度字段解释：`ω = -raw × sensitivity`，单位为 (rad/s)/输入单位，再独立按机构请求上限限幅；GimbalAxis 用真实执行周期积分一次。Yaw/Pitch 灵敏度初值为 0.002/0.0016，保持原映射未饱和区比例，右键不改变比例。当前 PC 客户端是否使用真实 counts、DPI 或其他缩放尚待确认，不能直接套用 rad/count 公式。

有限关节的 Rate 目标同时受机械范围和相对实际角的领先角限制。样例领先角初值 Yaw 0.15 rad、Pitch 0.10 rad，均需逐轴标定；限制触发时会舍弃超出机构能力的输入。失联、无效周期、禁用和参考变更清除旧目标，恢复时从新鲜同坐标反馈重建。当前仍为关节控制；惯性稳定与大 Yaw 协同需要有效 IMU 和安装标定后另行接入。

## 调参入口

所有新增可调参数与现有控制参数组均有注释，先保持摩擦关闭，在行程内调瞄准，再做无弹发射调参。

| 文件 | 参数与作用 |
| --- | --- |
| `../command_gimbal/src/board_config.hpp` | 样例输入来源、500/250 ms 手势时间、独立鼠标灵敏度、云台请求限速、领先角、位置/速度 PID、死区、反馈滤波、升降斜率 |
| `include/robotics/vehicle/shooter_profile.hpp` | 统一射频、摩擦就绪、拨盘到位/稳定/超时、速度/电流控制参数 |
| `include/robotics/vehicle/calibration.hpp` | 安装方向、减速比、机械范围、摩擦速度、每格角度、拨盘速度上限和每发热量 |
| `../common/rc_controls.hpp` | 100 ms 输入失联、500 ms 解锁归中、1000 ms 清故障手势 |

不要同时改变 DPI、灵敏度、PID 与滤波。现有工作区 PID/机械范围数值未重新标定，尤其 Pitch 软件范围 2.50～3.50 rad 是否符合实际端点需确认。目标领先限幅不能替代机械限位。

## 构建

```sh
west build -b dm_mc02/stm32h723xx samples/robotics/gimbal_shared_can -d /tmp/skywalker-gimbal-mouse-build
```

诊断场景说明见 [统一遥控操作](../common/REMOTE_CONTROL.md)。普通构建不注入故障；场景 1 暂停消费命令快照，场景 2 暂停执行更新，操作门控继续监督输入。

## USB VOFA 遥测

默认 USB CDC / JustFloat，19 通道，发送周期初值 20 ms（50 Hz）。发送为有界非阻塞入队；console 另以 200 ms 周期输出输入来源、手势类别、最近接受/拒绝事件、完成单发数、预留供弹数、执行模式与故障。低频观测不能证明每个原始输入帧都到达或替代控制周期级采样。

默认发射布局：

| 通道，从 0 开始 | 数据 |
| --- | --- |
| 0 | 发送尝试帧号，1000000 回绕 |
| 1/2、3/4 | 左、右摩擦请求/实际速度，rad/s |
| 5/6 | 拨盘位置目标/实际位置，rad；速度模式以状态报告的目标含义为准 |
| 7 | 拨盘实际输出轴速度，rad/s |
| 8/9 | 当前拨盘控制器指令/反馈电流，A |
| 10 | 摩擦实际就绪 |
| 11/12 | 拨盘 RunState / WaitReason |
| 13 | DialControlMode：0禁用、1单发位置、2连发速度、3减速速度、4位置保持 |
| 14 | 卡滞锁存 |
| 15 | 有效位掩码 |
| 16/17 | 拨盘请求/实际输出轴速度，rad/s |
| 18 | 拨盘电机轴 rpm，按配置减速比换算 |

CH15 bit0～bit6 为左摩擦速度、右摩擦速度、拨盘位置、拨盘速度、拨盘电流、拨盘指令、拨盘请求速度有效。无效值填零，结合有效位使用；位置模式的 CH16 为内环速度参考，速度模式为统一射频生成的请求。

设置 `CONFIG_SHOOTER_MOUSE_AIM_TELEMETRY=y` 可切换到瞄准布局；仍为19通道，不能按旧发射布局解释：

| 通道 | 数据 |
| --- | --- |
| 0 | 发送尝试帧号 |
| 1/2 | 原始输入序号/接收时间戳 ms，均1000000回绕 |
| 3 | 原始输入年龄 ms，无有效戳为 -1 |
| 4/5 | 原始鼠标 X/Y |
| 6 | 本轮实际云台 dt，s；执行暂停时零 |
| 7/8 | Yaw 目标/实际角，rad |
| 9/10/11 | Yaw 内环参考/实际速度 rad/s、指令电流 A |
| 12/13 | Pitch 目标/实际角，rad |
| 14/15/16 | Pitch 内环参考/实际速度 rad/s、指令力矩 N·m |
| 17 | 有效位：bit0/1两轴位置，bit2/3速度，bit4/5输出，bit6/7目标，bit8真实输入新鲜 |
| 18 | 限幅位：bit0～2 Yaw速率/机械/领先，bit3～5 Pitch速率/机械/领先，bit6/7 Yaw位置/速度PID饱和，bit8/9 Pitch位置/速度PID饱和，bit10仲裁请求限幅 |

原始戳与控制 dt 分属不同节奏，不用 PC 时间直接减 MCU 时间。用目标与实际响应分辨软件目标拖尾和机械追赶；图传延迟需独立测量。更多人工调参方法见 [实施指南](../../../docs/dev/鼠标发射手势与单双发控制实施指南.md)。
