# 云台共享 CAN 空载组合

CAN1 同时 attach 小 Yaw GM6020、两个摩擦轮 M3508 和拨盘 M2006，Pitch DM4310 在 CAN2。三个故障组分别为小 Yaw/Pitch、两个摩擦轮、单拨盘；执行器只暂存目标，应用每 5 ms 在所有控制更新结束后各提交一次 CAN。连接与方向读取 `include/robotics/vehicle/calibration.hpp`，确认开关默认 false。

本入口为无弹空载资源验证。纯物理 RC 仲裁控制云台：安全档归中解锁后，右 Middle 预热摩擦，Middle→Up 单发，保持 Up 500 ms 连续供弹，回 Middle 停供弹、右 Down 停摩擦。左 Down 停机，安全档手势复位。console 不再接收控制指令。先确认摩擦达到目标和 dwell，再拨盘分度；恢复不重放旧事件，卡滞需清除。事件的编号和原始生产时间独立于仲裁序号。

```sh
west build -p always -b dm_mc02/stm32h723xx samples/robotics/gimbal_shared_can -d build/gimbal_shared_can
```

云台参数已同步自当前 `gimbal_control/src/board_config.hpp`，实际生效位置为
`../command_gimbal/src/board_config.hpp` 与 `include/robotics/vehicle/calibration.hpp`；其他使用这两个公共配置的入口也会获得这些参数。

- yaw：位置 PID (20, 0.5, 1.48)，速度 PID (0.33, 0.55, 0.00005)，控制输出 ±1.2 A。
- pitch：CAN2 / ID1 / Master 0x00，驱动力矩限幅 1.0 N·m；位置 PID (10, 0.1, 0)，速度 PID (0.25, 0.20, 0)，积分限幅 ±0.7 N·m，速度 PID 输出限幅 ±1.8 N·m，最终控制输出限幅 ±0.8 N·m。
- pitch 速度参考升降斜率 8 rad/s²，速度滤波时间常数 0.02 s，速度软死区 0.02 rad/s，最大速度 5 rad/s。
- pitch 软件范围按当前简单示例复制为 2.50～3.50 rad；已报告的机械端点为 2.65～3.40 rad，软件范围覆盖端点外区域。

`connections_confirmed` 仍为 false：当前仅同步云台参数，五电机连接确认尚未完成；此值为 false 时启动返回 `-ENODEV`。确认五电机连接后再修改该公共确认开关。遥控仲裁的最大请求速度仍为 yaw 1.0 rad/s、pitch 0.8 rad/s，因此满杆目标变化速度与简单示例不同。

## USB VOFA 发射机构遥测

默认启用 USB CDC，选择枚举出的 USB 串口和 JustFloat 协议，50 Hz、固定16通道。console 保留原板载串口。USB未连接不阻塞控制；发送失败按错误变化打印，入队成功不代表主机收到。仅增加观测，不改变控制和许可条件。

| 通道（从0开始） | 数据 |
| --- | --- |
| CH0 | 帧号，每次发送尝试递增，1000000回绕 |
| CH1 / CH2 | 左摩擦轮请求 / 实际速度，rad/s |
| CH3 / CH4 | 右摩擦轮请求 / 实际速度，rad/s，保留方向符号 |
| CH5 / CH6 | 拨盘目标 / 实际位置，rad，驱动连续坐标 |
| CH7 | 拨盘实际速度，rad/s |
| CH8 / CH9 | 拨盘指令 / 反馈电流，A |
| CH10 | 摩擦轮就绪 ready |
| CH11 | 拨盘执行状态：0禁用、1恢复、2Active、3阻塞 |
| CH12 | 等待原因：0无、1命令、2传输、3反馈、4参考、5配置、6驱动/就绪门控、7许可/热量、8周期 |
| CH13 | 拨盘 busy |
| CH14 | 卡滞锁存 jam |
| CH15 | 有效位掩码，见下文 |

CH15 的 bit0～bit5 依次表示：左实际速度、右实际速度、拨盘位置、拨盘速度、拨盘反馈电流、拨盘指令电流有效，全部有效时为63。无效测量和指令填0，必须结合有效位判断；目标保留时不能当作仍在执行。摩擦轮请求是最终目标，不是内部斜坡后的速度参考。指令电流不代表电机已执行。

排查停止时重点叠加 CH5/CH6、CH8/CH9，并观察 CH10/CH14：ready先掉表示就绪条件中断；ready保持而jam变1表示拨盘动作超时。帧号用于识别数据流是否继续；诊断场景3仍会暂停遥测，场景2执行暂停时输出指令标为无效。

拨盘响应参数：位置 Kp=6，位置环输出上限 ±2 rad/s；独立速度 PID=(0.45, 0.05, 0)，速度参考升降斜率20 rad/s²。速度环积分、输出与最终电流限幅统一为 min(0.5 A, dial.effort_limit)。拨盘不再继承摩擦轮PID，动作超时仍为1.5秒；此参数需空载实机确认到位时间与振荡情况。
