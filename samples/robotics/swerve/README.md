# 一套真实舵轮模块

本样例把 GM6020 舵向和 M3508 驱动绑定到同一条 CAN1，再放入一个 Group。两台均为 ID1，但反馈 ID 与 DJI 命令帧不同；CanBus 统一路由和组帧。只接一套悬空舵轮，不把固件直接用于完整八电机底盘。

## 配置

`src/board_config.hpp` 是电机型号、ID、电流限幅、GM6020 零点、M3508 减速比、方向、轮径和 PID 的单一配置源。当前示例为 GM6020 电流模式 ID1、0.5 A 与 M3508 ID1、0.5 A、减速比 3591/187，均在 CAN1。`app.overlay` 只保留硬件 overlay 入口；CAN1 来自 MC02 板级 DTS。控制台是板级 USART10，115200 baud。

上电先由 CanBus.start 接管 CAN 并建立安全状态。两轴有新鲜反馈且稳定后，应用用 GM6020 校准绝对角和 M3508 当前点重建连续参考，再重置舵轮算法。按 `e` 后由 Group.enable 同时请求两轴准备；只有 Group.active 时，两个电流 setter 才写命令，每周期一次 commit。同组任一端点异常会让两个槽位安全撤销。

## 操作

`e` 请求使能；`w/s` 前后、`a/d` 左右、`q` 旋转分量。运动学计算四个安装点，此样例只把 FL 目标交给真实模块。空格禁用，`!` 锁存急停，`r` 解除锁存并请求清除电机故障；故障或急停后都需新的 `e` 和稳定反馈。确认悬空、零点、方向及限幅后再给电机动力，先观察低电流和停机帧。

## 构建

```sh
west build -b dm_mc02 samples/robotics/swerve -d ../build/bench_swerve
```

已在 MC02 编译链接通过；未刷写或实机验证。日志显示 Group、反馈、CAN 状态与舵向/驱动目标。
