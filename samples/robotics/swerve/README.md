# 单舵轮双 CAN 台架

GM6020 舵向接 CAN1，M3508 轮驱动接 CAN2，两台均为各自总线 ID1。应用创建两个 `CanBus` 和一个跨总线故障组。每 5 ms 运行真实 `SwerveModule`，两条物理 CAN 各提交一次；任一轴或总线失效撤销同组两台电机。

机械参数统一取 `include/robotics/vehicle/calibration.hpp` 的 FL 配置，模块控制参数复用 `../common/chassis_bench.hpp`。默认 `connections_confirmed=false`，入口仍保持观测循环，输出禁用。TODO 需要确认电机 ID、电流模式、舵向零点、方向、减速比、轮径、限流和控制参数；悬空确认后才开启确认标志。

恢复过程先撤销旧目标，等新鲜反馈和总线恢复，再把舵向绝对角和驱动当前点作为连续参考，等待两轴各产生新反馈，重置模块与运动学。`RecoveryGate` 拒绝恢复边界之前的输入，且在使能握手期间继续监督命令年龄。暂态故障自动恢复；急停和需要显式清除的故障由 `r` 处理。

控制台：`e` 请求使能；空格禁用；`w/s` 前后、`a/d` 左右、`q/z` 正负旋转、`0` 零速度；`p` 暂停/恢复样例输入生产；`!` 急停；`r` 清除故障并撤销请求。样例只把四轮运动学中的 FL 目标交给真实单模块，完整八电机请使用 `four_swerve`。

先单轴确认方向、轮径换算和共同停机，再验证正反转、跨 ±pi 的翻轮、命令停产、单轴断流、CAN1/CAN2 断流及恢复。日志记录源序号、原始年龄、恢复代次、等待原因、双总线状态和实际机械反馈。
