# 底盘功率台架

复用 `four_swerve` 的八电机双 CAN 拓扑，在真实底盘执行器中接入 `RefereeReceiver` 的底盘权限、功率上限和缓冲能量，以及裁判实际测得的底盘功率。USART1 PA10 接裁判 User TX，PA9 为 TX，并共地；控制台使用板级独立 UART。协议默认显式 RM2026 V1.3，需要按实板固件确认，不能仅凭帧长猜测字段。

`include/robotics/chassis/power_measurement.hpp` 提供真实测量源合同，包含独立生产时间、有效性、来源、功率，以及可选电压/电流。`../common/chassis_bench.hpp` 的 `run` 可以注入 `IPowerMeasurementSource` 接真实 ADC 或功率监测器；当前默认使用裁判测量值，保留它的原始生产时间。TODO 保留外部电流/电压采集和模型标定入口。没有传感器数据时不会生成有效测量；没有真实裁判帧时不会生成有效权限或预算。

每周期控制更新后，把真实功率、上限和缓冲送入 `ChassisPowerLimiter`，再缩放八电机电流输出。权限、预算、测量任一过期，都撤销输出；恢复需要新鲜权限、预算及恢复边界之后的新命令。估计功率回退默认禁用，仅在中央模型标定完成并显式允许时可启用，而且始终标为 Estimated。

中央 `connections_confirmed=false` 默认阻止电机启用。功率控制完成标志也默认关闭，即使测量有效，台架电流缩放仍不超过 0.15。当前限制器是基础台架策略；TODO 在实测模型、缓冲下降、周期负载和舵向误差验收后再打开完整功率控制。

控制台操作沿用 `four_swerve`。重点操作 `m` 停止测量生产，保留裁判通信和预算更新；预期测量过期后撤销底盘输出。随后恢复测量，观察新的恢复代次和边界。再分别验证裁判断流、输出许可关闭、预算下降、缓冲下降、命令暂停、执行暂停和单 CAN 失效。日志给出真实功率、预算、测量有效性、电流缩放以及舵角和轮速目标。

```sh
west build -b dm_mc02 samples/robotics/chassis_power -d ../build/chassis_power
```
