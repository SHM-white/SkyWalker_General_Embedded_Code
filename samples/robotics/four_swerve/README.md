# 四舵轮悬空台架

入口真实创建四个 GM6020 舵向、四个 M3508 轮驱动、一个八电机故障组和两条 CAN；运行完整 `SwerveChassis`。顺序统一为 FL、FR、RL、RR。CAN1 仅接四个舵向，CAN2 仅接四个轮驱动，电机 ID 均按各自总线的 1..4 配置。

所有机械标定取自 `include/robotics/vehicle/calibration.hpp`。默认 `connections_confirmed=false`，主循环持续报告 Configuration，但不启动电机总线。先填 TODO 中的 ID、电流模式、零点、方向、减速比、轮径、轴距、轮距，再在真实悬空台架确认后修改确认标志。低电流控制参数在 `../common/chassis_bench.hpp`；在未完成功率控制标定时统一保留 0.15 电流缩放上限。

`SwerveHardware` 和 `ChassisExecutor` 都不持有 CAN。应用在每周期所有目标写完后，对 CAN1、CAN2 各提交一次。八台任一成员失效会撤销整个底盘组；大 Yaw 不属于该组。反馈恢复后重新建立机械参考并重置控制历史，恢复边界之后的新来源数据才能重新请求使能。急停与非暂态故障使用显式 `r` 清除。

控制台：`e` 请求使能，空格禁用，`w/s` 前后，`a/d` 左右，`q/z` 正负旋转，`0` 零速度；`!` 锁存急停，`r` 清除并撤销当前请求。`p` 暂停/恢复命令源，`x` 暂停/恢复执行更新，`m` 暂停/恢复功率测量生产。执行暂停后电机命令由驱动层时限撤销；日志仍运行且不会刷新执行状态生产时间。

建议实板顺序：逐轮核对映射和方向；四轮小速度平移；左右平移；纯旋转；组合运动；命令生产暂停；执行生产暂停；单电机断流；整条 CAN 断流；反馈恢复。记录源序号/年龄、状态生产年龄、恢复代次、等待原因、四轮舵角与速度，以及两条 CAN 状态。恢复时不应重放故障期间的旧目标。

```sh
west build -b dm_mc02 samples/robotics/four_swerve -d ../build/four_swerve
```
