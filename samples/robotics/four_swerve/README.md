# 四舵轮悬空台架

入口真实创建四个 GM6020 舵向、四个 M3508 轮驱动、一个八电机故障组和两条 CAN；运行完整 `SwerveChassis`。顺序统一为 FL、FR、RL、RR。CAN1 仅接四个舵向，CAN3 仅接四个轮驱动，电机 ID 均按各自总线的 1..4 配置。

所有机械标定取自 `include/robotics/vehicle/calibration.hpp`。默认 `connections_confirmed=false`，主循环持续报告 Configuration，但不启动电机总线。先填 TODO 中的 ID、电流模式、零点、方向、减速比、轮径、轴距、轮距，再在真实悬空台架确认后修改确认标志。控制参数在 `include/robotics/vehicle/swerve_profile.hpp`；未完成功率控制标定时采用显式台架电流上限：舵向 0.8 A、驱动 0.5 A，独立缩放默认均为 1；功率约束仍会同时收缩两类输出。

`SwerveHardware` 和 `ChassisExecutor` 都不持有 CAN。应用在每周期所有目标写完后，对 CAN1、CAN3 各提交一次。八台任一成员失效会撤销整个底盘组；大 Yaw 不属于该组。反馈恢复后重新建立机械参考并重置控制历史，恢复边界之后的新来源数据才能重新请求使能。急停与非暂态故障使用显式 `r` 清除。

控制台：`e` 请求使能，空格禁用，`w/s` 前后，`a/d` 左右，`q/z` 正负旋转，`0` 零速度；`!` 锁存急停，`r` 清除并撤销当前请求。`p` 暂停/恢复命令源，`x` 暂停/恢复执行更新，`m` 暂停/恢复功率测量生产。执行暂停后电机命令由驱动层时限撤销；日志仍运行且不会刷新执行状态生产时间。

建议实板顺序：逐轮核对映射和方向；四轮小速度平移；左右平移；纯旋转；组合运动；命令生产暂停；执行生产暂停；单电机断流；整条 CAN 断流；反馈恢复。记录源序号/年龄、状态生产年龄、恢复代次、等待原因、四轮舵角与速度，以及两条 CAN 状态。恢复时不应重放故障期间的旧目标。

```sh
west build -b dm_mc02 samples/robotics/four_swerve -d ../build/four_swerve
```

框架已实现；本轮没有执行构建或实板测试，机械验收阈值仍需单轮标定确定。

## 参考底盘适配

中央标定已录入参考工程的四轮候选零位 3060/2421/2383/3097、驱动方向 -/+/-/+、减速比 3591/187；仍需核对装配、GM6020 电流模式和几何尺寸，`connections_confirmed` 保持 false。几何沿用待测默认值，不使用参考工程经验性的半径 0.01 m。

控制共享 95°/85°翻转滞回、4 rad/s 舵角目标限速、最终方向误差 0.10/0.40 rad 驱动门控、cos 补偿，以及 0.01/0.02 m/s 低速滞回。四轮版本默认所有非零向量模块对齐后才放行驱动；未对齐时驱动零电流并重置积分/斜坡。零指令默认 Coast（卸力），可在 profile 选择 Hold（保角及零速制动），Disabled 始终撤销。

控制台新增 `u/j` 前进叠加正/负旋转。`e` 从零命令开始使能；运动键只更新目标，不会自动使能。每次使能/运动键续期 1 秒，过期撤销并需重新按 `e`，可按住运动键由终端重复发送。`0` 为零指令卸力。来源暂停仍保留原时间戳；正常运行也不会用不断刷新的内部时间戳掩盖控制台失联。

控制周期采用 2 ms 绝对节拍，迟到跳过错过的时隙，不突发补算。日志使用 deferred logging；四轮遥测每 500 ms 记录限速目标、最终误差、驱动放行、翻转、卸力与电流，避免阻塞电机控制。完整设计见 [舵轮参考移植](../../../docs/dev/舵轮参考移植.md)。
