# 机构样例的遥控操作

机器人机构样例以及 `motor/mixed_topology` 使用物理遥控器。console 输出日志，VOFA 输出遥测，不接收运动、复位或故障注入指令。单电机模块样例、遥控诊断和纯传感器观察保持各自用途。

## 接线与输入

复用板级 `remote-uart`：MC02 为 UART5 / PD2 RX，Type C 为 USART3 / PC11 RX，100000 baud、8E1。接收机 TX 接 RX 并共地；保留板卡已有的 DBUS 电气通路。日志与遥测使用各自独立端口。

机构样例启用第五通道拨轮解码，不使用透传键鼠。先用 `samples/communication/dr16` 确认物理左右开关与通道对应，再连接执行器。若接收机没有符合扩展定义的拨轮通道，需要按实测结果调整 `receiverConfig()`，并给所需旋转或第三组运行通道重新安排输入。

## 日常操作

| 输入 | 行为 |
| --- | --- |
| 左 Down | 安全档，撤销运行授权、停止机构 |
| 左 Down、右 Down，双摇杆和拨轮归中 500 ms，再拨左 Middle | 解锁手动运行 |
| 已解锁后拨左 Up | 仅已配置视觉执行的样例进入自动模式，其他样例禁用 |
| 左摇杆 | 底盘前后、横移 |
| 右摇杆 | 云台 Yaw、Pitch |
| 拨轮 | 底盘旋转 |

中立要求每个原始通道在 ±33 内；通道已经减去 1024 中心。连续运动输入使用 ±660 范围与 0.03 死区。回中后底盘速度归零，云台保持目标。速度、方向、机械范围和输出限幅沿用对应样例的配置。

开机时已在运行档不会解锁。遥控原始输入超过 100 ms 未更新便撤权，接收恢复后须重新完成安全档解锁。电机准备、使能握手和执行期间均继续监督输入。读取缓存、仲裁和通信重传不能延长旧输入的有效期。

## 清故障

先回左 Down、右 Down，并将摇杆和拨轮归中保持 500 ms。继续保持左 Down 和中立，将右开关拨 Up 保持 1 秒，产生一次清故障请求。停留 Up 不会重复请求；再次复位须先回右 Down。清除后重新完成解锁动作。

清故障只处理执行器允许清除的条件，不使能电机。物理急停未释放时仍优先停机。日志中的“请求”不是远端已完成复位的确认。

## 发射、小 Yaw 与分组例程

发射例程右 Down 停摩擦轮，Middle 预热，Middle→Up 单发一次。保持 Up 500 ms 后转为连续发射，回 Middle 停供弹。每个单发事件只消费一次，忙碌、摩擦未就绪或许可不满足时丢弃，不在稍后补发。视觉发射仍须右 Up 持续授权；裁判许可、热量、机械回零、云台稳定及硬件确认继续生效。

小 Yaw 例程右 Down 选择速率、Middle 选择 Hold、Up 选择绝对角。进入绝对角模式先保持目标，右横杆的新正向动作选择 0.5 rad，新负向动作选择 0 rad；每次动作前先回中。

`mixed_topology` 的左纵杆、右纵杆、拨轮依次控制最多三个组。全局解锁后，通道正向超过 0.6 请求对应组运行，低于 0.3 停止。输出保持例程原有的小电流/力矩。跨 CAN 联动组占第一通道，两独立组占后两通道；某独立组故障后必须松杆再推起，其他独立组可继续运行。

## 独立诊断固件

普通构建的 `CONFIG_SAMPLE_DIAGNOSTIC_SCENARIO=0`，不注入故障。相关样例提供 `diagnostic.conf`；也可在最终构建时指定该样例支持的场景。

| 值 | 场景 |
| ---: | --- |
| 1 | 命令/输入生产暂停 |
| 2 | 执行更新暂停 |
| 3 | 执行状态发布暂停 |
| 4 | 头部 IMU 输入暂停 |
| 5 | 视觉来源暂停 |
| 6 | 裁判权限来源暂停 |
| 7 | 功率测量暂停 |
| 8 | 轮底盘恢复代次变化 |
| 9 | 大 Yaw 恢复代次变化 |
| 10 | 错误板间协议标识 |

每种样例支持的场景见自身 README。首次稳定 Active 3 秒后演练一次，暂停类场景持续 1.5 秒。安全档或真实遥控掉线取消本次演练。管理线程和定时器始终继续运行，演练不能重新授权运动。无执行器的板间通信例程以链路在线为启动条件。

## 双板与上电顺序

双板仅在云台板接遥控器，两端使用相同的当前协议固件。先将遥控器置于安全档并归中，给控制板供电，观察接收与链路状态；随后给无弹、架空或机械隔离后的执行器供电，最后解锁。loaded 发射仍需实际许可、热量和拨盘参考来源，未接入的来源不会被模拟有效值替代。

统一板间协议只接受标识 4，不协商旧格式。管理消息携带原始 RC 年龄和目标 boot，停机与复位不依赖正在演练的业务命令生产。原始输入、执行状态、物理 CAN 和电机驱动各自保持有效期与撤权条件。
