# 多电机拓扑与独立执行

四种编译拓扑演示同帧 DJI、共享 DM Master ID、跨 CAN 批量 Group，以及跨 CAN 与单轴 Group 同时存在。

Group 仅是用户批量启停工具。一个成员掉线不会撤销其他成员；同一 DJI 帧按槽位独立决定输出，单路 CAN 故障也不停止另一路发布。

遥控两开关 Down、通道归中 0.5 秒，随后左 Middle 解锁。左／右纵向通道和拨轮选择各组：超过 0.6 请求运行，回到 0.3 以下停止。这个输入滞回只读取用户通道，不读取电机状态。遥控失联或用户停止取消请求；电机恢复不要求新的通道边沿。

每周期对请求运行的所有成员更新目标，再对每个物理 CAN commit 一次。日志显示各轴 requested、实际 state、fresh、历史 fault，以及 Group 数量统计。

使用仓库原有 `MIXED_TOPOLOGY` CMake 选项和板级配置；首次台架运行应核对型号、ID、模式、量程与机械方向，并让输出轴空载。
