# DM J4310 样例

所有样例在配置完成后持续表达控制意图。驱动工作线程处理 Enable、反馈确认、ClearError 和限频重试；缺席或掉线不会使主循环退出。

| 样例 | 命令 |
| --- | --- |
| dm_mit_control | MIT 直接力矩 |
| dm_velocity_control | 原生速度 |
| dm_position_control | 原生位置＋速度限制 |
| dm_mit_velocity_control | MIT 力矩输出的速度控制器 |
| dm_mit_position_control | MIT 力矩输出的连续位置控制器 |
| recovery＋RECOVERY_DM | 控制台启停、持续速度目标、掉电恢复 |

使用 CAN1、ID1、Master ID0x11，各入口明确配置协议量程和力矩上限。MC02 的对应示例先注册 CAN 端点，再打开 power1；应用不等待全套反馈准备后才产生目标。

原生位置使用驱动的实际原生坐标。软件连续位置控制在参考丢失后等待可信坐标补充，不能自动重新置零。绝对角模式只能用于具有可信校准绝对角能力的设备。

VOFA、温度和电流／力矩反馈用于诊断，温度显示不构成另一层锁存停机。协议参数范围和显式 effort 上限仍生效。用户停止和命令源过期由输入边界处理。

电机恢复后可能自行运动，这是持续运行请求的预期结果；首次观察让机构空载。样例不通过放宽反馈超时或 CAN 位时序实现恢复。
