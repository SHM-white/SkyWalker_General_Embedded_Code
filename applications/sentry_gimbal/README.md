# 哨兵云台应用

固定手动编码器双轴云台、大 Yaw 回中和底盘行走发送入口，配未修改的参考底盘 `JJL0612/sentry_onlychassis@dcc8d4e`。本地小 Yaw/Pitch 由 CAN1/CAN2 电机编码器闭环；板载 BMI088 随大 Yaw 转动。当前不启动 CAN3 外置头部 IMU、视觉、裁判或发射机构。

```sh
west build -b dm_mc02/stm32h723xx applications/sentry_gimbal -d ../build/applications/sentry_gimbal
west flash -d ../build/applications/sentry_gimbal
```

只需重新编译、烧录云台板，不修改参考底盘或 v4 协议。不叠加历史 `vision_*.conf`、`imu_*.conf` 等场景配置；未来视觉功能见[视觉姿态回传与外置 IMU 接管方案](../../docs/dev/云台视觉姿态回传与外置IMU接管方案.md)。这些旧 conf 文件存在不代表当前固定入口启动了视觉。

## 反馈与控制

本地手动控制不检查外置 IMU 初始化、姿态、角速度或 CAN3 回传期限。小 Yaw/Pitch 的 PID、驱动方向、原点与机械限位继续由共享 `calibration.hpp` / `gimbal_profile.hpp` 提供。没有板载航向时，本地仍可执行编码器手动闭环，大 Yaw 请求保持 Disabled。

有新鲜的板载载体角速度时，小 Yaw 关节速度按 `small_yaw.direction × (手动世界角速度请求 - 载体世界角速度)` 计算。这样大 Yaw 转动时小 Yaw 会反向补偿，相对编码器偏角才能逐渐回中；若只锁住相对编码器角，大 Yaw 与小 Yaw 会一起转、偏角不会消除。该补偿不使用外置 IMU，也不等同于完整的头部实测姿态闭环；Pitch 采用编码器相对角控制，暂不执行外置 IMU 的世界俯仰稳向。

大 Yaw 请求来自小 Yaw 编码器相对 `yaw_center_rad` 的偏角：增益 6.0，速度上限 1 rad/s，加速度 4 rad/s²，停止死区 0.003 rad，重新跟随门限 0.005 rad。板载航向、真实小 Yaw 反馈和小 Yaw 输出有效才放行；不再以外置 IMU 或 Pitch 惯性输出作为前提。远端实际速度缺失时只发授权零速以启动反馈；参考反馈接收期限 250 ms，匹配其 100 ms 上报周期。

参考底盘持续用云台板载航向/角速度及底盘自身陀螺控制大 Yaw，不以小陀螺开启为前提。`0x0402 mode=1` 是世界系角速度意图，不乘电机安装反号；`0x0404/32B` 发布板载 BMI088 载体航向与去偏角速度。板载 IMU 不跟随小 Yaw；不能将其航向直接当成枪口的世界航向。

本入口采用近似水平的独立 gyro-z 航向，适用于板载 IMU 固定在大 Yaw 载体上、转轴近似竖直的车辆。安装转换仍使用 `carrier_sensor_to_body`。不能用于明显坡度/倾斜下的严格世界航向控制；纯陀螺的长期 yaw 漂移仍需外部参考解决。

[`PlanarYawIntegrator`](../../include/control/planar_yaw.hpp) 在 BMI088 采集线程处理每个新陀螺样本，而不是在 5 ms 应用线程抽样积分。上电先等待 1 秒，再要求连续至少 1 秒且至少 800 个静止样本：陀螺三轴模长小于 0.05 rad/s、加速度模长在重力 ±1 m/s² 内，z 轴标准差不超过 0.01 rad/s。运动或输入缺失会重新累计静止窗口。校准完成时捕获 yaw=0，固定 z 轴零偏，随后按真实陀螺时间戳用梯形积分更新 yaw，输出角度约束到 ±π；启停遥控和小陀螺都不重新归零。

完整三维 EKF 保留用于诊断，但不再提供本入口的 yaw 或零偏。`correct_gyro_bias=false` 防止 EKF 初始化/重置引起 gyro 坐标中的偏置阶跃；独立通道自身减去启动零偏。运行期间加速度修正拒绝、EKF Degraded、EKF 重置或加速度读失败，都不会单独撤销已校准的 yaw，也不需要 Tracking 的 100 ms 许可窗口。其他使用 `ImuHeadingReference` 的入口维持原逻辑。

陀螺非法/读失败会立即发布无效 yaw；相邻有效陀螺样本间隔不超过 20 ms 时允许短缺口梯形连接，不重复积分缓存，不重新捕获参考。有效采样间隔超过 20 ms 或时间倒退时锁定无效，无法推算缺失期间转过的角度，必须停机并重启云台板重新静止标定。有效航向仍须满足 20 ms 新鲜度，角速度范围为协议允许的 ±35 rad/s。参考代次独立于 EKF，初始化完成为 1、已建立参考发生不可恢复中断后为 2。链路/遥控有效期、失联撤权和电机保护维持原处理。

## 资源与操作

| 资源 | 当前用途 |
| --- | --- |
| UART5 | DR16 遥控 |
| USART10 PE3/PE2，460800 8N1 | 对参考底盘的 v4 板间链路 |
| UART7 PE8/PE7，115200 8N1 | 唯一诊断串口，不能同时给视觉 |
| CAN1 / CAN2 | 小 Yaw / Pitch 电机 |
| SPI accel0 / gyro0 | 大 Yaw 载体上的板载 BMI088 |
| CAN3 | 当前无外置 IMU 接收实例；留给未来头部实测姿态 |

共享配置仍可能编译外置 IMU 驱动，但没有实例化或启动它，不会因 CAN3 无回传而阻止手动控制。不在本次修改共享接线或其他惯性实验入口。

上电保持未解锁、静止约 3 秒，并等待诊断 I22=1（实际标定完成才允许大 Yaw）。左 Down、右 Middle，摇杆/拨轮归中保持至少 500 ms，左 Down→Middle 建立解锁，再拨 Up 手动。右杆控制小 Yaw/Pitch，左杆控制云台坐标内前后/横移，速度由当前 [calibration.hpp](../../include/robotics/vehicle/calibration.hpp) 决定；进入手动后右拨杆先经过 Middle，再主动切 Down 才请求小陀螺。拨轮不再叠加大 Yaw 速度，以免打断自动回中。左 Down 停止；当前没有导航、自动视觉或发射执行。

应用每 5 ms 控制，每 10 ms 发布大 Yaw 与行走请求。先确认小幅输入和撤权停止，再从中心两侧验证回中方向；编码器中心和 IMU 安装方向仍须实测，不能以候选标定或编译结果代替。

## 诊断

共享 VOFA 输出仍为 46 通道，I19=103 标识独立 gyro-z 云台版本（旧 EKF 航向版本为 102）。完整表见 [诊断操作指南](../../docs/dev/大Yaw突发跟转诊断操作指南.md)。I8/I9 为小 Yaw 关节目标/反馈角 rad；I7 表示本地执行 Active，不代表远端大 Yaw armed。I10 为独立 yaw 样本年龄 ms，未建立或无效时 -1；I11/I13 保留最近失效周期/原因；I17 为中心偏角 rad；I18 为独立通道去零偏后的 gyro-z rad/s，无效时 NaN。

I13/I20 原因码：0 正常；1 源未运行；3 陀螺/yaw 时间戳过期或处于未来；4 无独立通道/参考；6 陀螺数值非法或读失败；9 时间倒退锁定；11 角速度非法或超 ±35 rad/s；12 启动静止标定未完成；13 有效陀螺采样间隔超过 20 ms 锁定。其余旧三维姿态原因不再由这个通道产生。

每个控制周期记录有效航向转为无效的事件，通道 11/13 保留最近一次事件直到下一次失效或重启；通道 5/10/18 显示当前状态，因此恢复后仍能读出失效原因。首次有效航向建立前，通道 13 显示当前等待原因。云台通道 13 使用这份航向原因表，底盘通道 13 使用其自身的执行器 WaitReason 表。

通道 14 仍为本地云台执行/初始化错误，没有混入 EKF 服务错误。I21/I26～I29/I40/I42/I43 仍是三维 EKF 诊断，不能当成 yaw 许可。预期急加减速时可以 I21=4、I26=2，但 I20=0、I22=1、I18 连续有效，I31 不增加，I37 不含 32。I24 是安装转换后的原始 gyro-z；有效时 `I24-I18` 约为固定启动零偏。I13=9/13 则需停机重启，重新解锁不会清除参考锁定。

`reason=6` 仅指当前使用的板载航向无效，不再表示 CAN3 无回传；本地手动可运行而大 Yaw 因板载航向或对端反馈被禁止。其他原因沿用共享诊断定义。尚未烧录或实板验证；视觉回传、自动瞄准、姿态源接管均只记录后续方案，未接入此固件。
